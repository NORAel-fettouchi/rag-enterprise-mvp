# Projet RAG Documentaire d'Entreprise

## Objectif

Créer une application permettant :

- Upload PDF
- Questions en langage naturel
- Réponses basées uniquement sur les documents
- Citations des sources

## Stack

- Python
- LangChain
- HuggingFace
- FAISS
- Streamlit

## V1

- PDF Loader
- Chunking
- Embeddings
- Vector Store FAISS
- Retrieval
- LLM
- Citations
- Interface Streamlit

## Contraintes

- Architecture simple
- Code clair
- MVP uniquement
